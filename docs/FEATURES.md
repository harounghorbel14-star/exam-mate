# Feature-completion matrix

Legend: ✅ implemented and covered by automated tests · 🟡 implemented with stated limits ·
❌ not implemented. **W** = web, **M** = mobile, **S** = server.

| Module | Status | Where | Notes |
|---|---|---|---|
| **A. Smart Scan** | 🟡 | W M S | Camera (explicit permission) / import, rotate, drag-crop (W), crop/edit via OS picker (M), local tesseract OCR (S) with in-browser fallback (W), editable text, multi-question splitting, MCQ choice detection, question-type detection, chemistry O/0 OCR repair, save to library, confidence %. Diagrams and handwriting are **not** interpreted. Mobile OCR needs the server. |
| **B. AI Question Solver** | 🟡 | W M S | Deterministic: geometry word problems (2D/3D, mixed units), algebra (linear, quadratic with exact surds, polynomial, transcendental, systems), calculus (derivatives, polynomial antiderivatives, numeric integrals), statistics, units, physics formulas (21) with word-problem parsing in en/fr/ar, chemistry balancing and molar mass. Biology, history, geography, languages and CS knowledge questions are answered **only** from the user's documents or a local model; otherwise the result is "unsupported". |
| **C. Quick Answer Mode** | ✅ | W M | Short / steps / explain simply / hint / check my answer / similar question; translate needs a local model. Preferred style is remembered (synced). Web shortcuts: Ctrl+Enter, Alt+1…7, `/`, Esc. |
| **D. Multi-language** | ✅ | W M S | en/fr/ar, full RTL on web (mobile needs an app restart to flip layout), math isolated LTR, language picker independent of the device, localised numbers and dates, OCR language selection, localised solver steps. New languages: add a typed dictionary (`packages/core/src/i18n`). |
| **E. PDF Brain** | 🟡 | W S (M: list/upload/ask) | PDF/DOCX/TXT/MD; background processing; RAG over Postgres full-text with page citations; summary, flashcards (saved as decks), quiz, revision sheet (premium), formulas and definitions; organised by course, exam and subject; deletion removes file and index. Generation is **extractive** (no model needed); scanned PDFs need OCR page by page. |
| **F. Math & Science Engine** | ✅ | W M S | KaTeX rendering, symbolic simplify/derivative, graph plotter, scientific notation, unit conversion with dimension checks, equation balancing, step-by-step derivations, independent numeric verification. Geometry diagrams are not drawn. |
| **G. Voice Tutor** | 🟡 | W (M: read-aloud) | Speech-to-text (Web Speech API, single utterance, explicit button), read-aloud with adjustable speed and language, text fallback. Follow-up questions are typed. STT depends on browser support; mobile STT is not implemented. |
| **H. Exam Simulator** | ✅ | W S (M: take + results) | Timed exams, MCQ / true-false / numeric / short / written, counts, difficulty, seeded randomisation, rubrics, auto-grading, manual review, results and per-question time analysis, wrong-answer review, custom question bank, templates, strategy mode (web). |
| **I. Memory Mode** | ✅ | W M S | SM-2 spaced repetition, active recall, daily sessions, formula/vocabulary decks, leech ("often forgotten") tracking, offline bundle and queued reviews. |
| **J. Weakness Detector** | ✅ | W M S | Weak topics and subjects, repeated mistakes, time management, explained reasons, multi-day plan with pin/skip/minutes overrides. |
| **K. Quick Tools** | ✅ | W (M: calculator, units, balancer, periodic table, formulas) | Calculator, scientific calculator, unit converter, formula library, periodic table, balancer + molar mass, graph plotter, notes (offline local / synced), study timer, saved questions, bookmarks, recent documents. Customisable order and visibility; offline vs online is labelled. Flashcards have their own section. |
| **L. Answer Verification** | ✅ | W M S | Second computation path for every deterministic tool; failed checks downgrade confidence; results stored with each solution; document answers quote the source; no invented citations. |
| **M. Personal AI Brain** | ✅ | W S | Level, subjects, goals, style and studied concepts; review, edit, delete, delete all; on/off switch; export; 180-day retention for inferred items; sensitive-data filter. |
| **Offline games (15)** | ✅ | W M | All 15 playable offline with scoring, levels, stars, restart, instructions, local persistence, conflict-free sync, downloadable packs (with integrity hash). Tested per game, level, locale and seed. |
| **Arcade (15 entertainment games)** | ✅ | W M | Separate from the 15 educational games (30 games in total). Tic-Tac-Toe (minimax AI / pass-and-play), Connect Four (alpha-beta AI / 2P), Snake, Falling Blocks (original 7-bag implementation, hold, ghost, levels), 2048 (saved board), Rock Paper Scissors (adaptive AI / hidden pass-and-play), Memory Match (4 grids, 1–2 players), Minesweeper (safe first click, flags, chording), Sudoku (generated with a verified unique solution, notes, hints, 3-mistake limit), Hangman (bundled en/fr/ar word lists, accent/hamza folding), Maze Escape (generated perfect mazes, time limit), Reaction Test (false starts and anticipation detection), Simon Says (speeds up; 6 pads on Hard), Checkers (mandatory and chained captures, kings, 40-move draw rule, AI), Pong (keyboard, touch, AI or 2P). Hub with cross-language search, categories, favourites, recents and a progress summary; shared shell with rules/controls, difficulty, mode, start/pause/resume/restart/game-over, records and streaks; synthesised sound (WebAudio on web; generated WAVs + expo-audio on mobile) and vibration, both switchable; all offline, no login; stats stored locally with optional conflict-free server sync. |
| **Online multiplayer & party games** | 🟡 | S W M | Private rooms with 6-character codes and invite links (web URLs; `exammate://play/<code>` on mobile), lobby with avatars, connection/ready state, game selection, player limit, kick and host migration. Server-authoritative Tic-Tac-Toe, Connect Four, Checkers and Rock Paper Scissors (2 players) plus party modes Memory challenge, Reaction race and Trivia (2–4 players) over an authenticated WebSocket on the existing server. Server-side validation, timers and CSPRNG randomness; per-player redaction of hidden information; stale/replayed/duplicate actions rejected; reconnection to the same seat, grace-period forfeits, abandoned-room sweeping and restart recovery from PostgreSQL. **Verified:** two and three independent browser clients completed real-time games through the real server (Playwright), plus multi-socket server tests. **Not verified:** play between physical phones, or across the public internet. Single API instance only (see LIMITATIONS). |
| **Exam Strategy Coach** | ✅ | W M | Time allocation, MCQ elimination expected value, pattern / checking / partial-credit tips, strategy practice mode, post-exam analysis. Restricted assessment mode disables the solvers. |
| **Auth & security** | ✅ | S W M | Includes optional two-factor sign-in (TOTP authenticator apps plus recovery codes). It is turned on in web Settings; the sign-in step works on web and mobile. Rate limits can be shared across instances. See [SECURITY.md](SECURITY.md). |
| **Monetisation** | 🟡 | S W | Free / Premium plans with configurable quotas and feature gates; **test-mode** checkout only. No real payment provider. |
| **Proprietary agent (no external AI)** | 🟡 | S | Loop, planner, tools, memory, RAG, budgets, traces, evaluation, classifier training with rollback, and a local model runtime are all implemented and tested. Answer quality with a real open-weight model is **not** verified (weights could not be downloaded here). |
| **PWA / offline web** | ✅ | W | Precached app shell, educational and arcade games, solver and tools; OCR assets cached on first use; offline queues sync on reconnect. |
| **Mobile app** | 🟡 | M | Home, Scan, Solver, Games (all 15), Arcade (all 15), Play online, Flashcards (offline), Documents, Exams, Tools, Coach, Progress, Settings / login. Tested with Jest and Metro bundles for both platforms; **not run on a device or emulator** here. |
